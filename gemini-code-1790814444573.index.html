重力與色彩反轉 (Gravity & Color Shift)

🎮 非傳統玩法：操作方式說明

  • 【切換重力】： 按下 空白鍵 Space 或 點擊螢幕左半區。角色會立即在天花板與地板之間翻轉切換（無跳躍功能）。
  • 【切換色彩】： 按下 Shift 鍵 或 點擊螢幕右半區。切換角色的黑/白顏色。
  • 【特殊遊戲機制】：
    • 障礙物有「黑色」與「白色」兩種。
    • 當角色與障礙物【顏色相同】時：可以安全直接穿過！
    • 當角色與障礙物【顏色不同】時：發生碰撞，遊戲結束！
  • 【遊戲目標】： 同時運用「重力翻轉」避開位置，與「色彩切換」吸收同色障礙，挑戰極限最高分！
